# Pimp My Police

Appli web pour fabriquer sa propre police (.ttf) à partir de lettres dessinées à la main.

- Version 0.2.0 : atelier avec repères pointillés et lettre fantôme (polices libres), stabilisation du trait, mode sans clic (pavé tactile), raccourcis Espace/Entrée, versions par lettre, lissage, recadrage automatique, export .ttf, historique, corbeille, aperçu.
- Tout reste sur l’appareil : aucune donnée envoyée, aucun traceur.
- À venir : alternance des versions dans une seule police, accents composés, installation sur l’écran d’accueil.

Conçu par Tom Rougeaud, avec l’aide de l’IA (Claude Sonnet 5.5, Anthropic).
