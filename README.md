# Pimp My Police

Appli web pour fabriquer sa propre police à partir de lettres dessinées à la main.

- Version 0.1.0 (palier 1) : atelier de dessin, versions par lettre, historique, corbeille, aperçu.
- Tout reste sur l’appareil : aucune donnée envoyée, aucun traceur.
- À venir : lissage, recadrage automatique, export .otf/.ttf, installation sur l’écran d’accueil.

Conçu par Tom Rougeaud, avec l’aide de l’IA (Claude Sonnet 5.5, Anthropic).
